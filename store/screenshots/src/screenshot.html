Plain text bookmarks

A bookmark is a small file: its path is the name of the bookmark and its content is the URL. Folders group related links, and the whole store fits in a git repository.

Every change becomes a commit that can be reviewed, reverted and pushed to a remote, so the same bookmarks follow from one machine to another.

The same store works from the terminal, from scripts and from the browser.
